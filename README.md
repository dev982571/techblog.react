# TechBlog

TechBlog is a React-based technology blog website that displays the latest technology articles. Users can search articles and add comments to individual article cards.

## Features

- Display technology articles using NewsAPI
- Search articles by title and description
- Show loading and error messages
- Display article images, titles, and descriptions
- Read full articles through external links
- Add comments to articles
- Responsive layout for different screen sizes
- Reusable React components

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- NewsAPI
